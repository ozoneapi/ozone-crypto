# Agent Workflow

This directory contains the agentic workflow configuration for this repository.

## Structure

- **overview/** - High-level project overviews and objectives
- **features/** - Individual feature definitions and specifications
- **plan/** - Implementation plans and roadmaps
- **defects/** - Bug reports and issues tracking
- **rules/** - Project-specific agent rules and guidelines

## Workflow

The agent workflow follows these stages:

1. Review constitution and overview documents
2. Generate features from overview
3. Review and refine feature files
4. Implement features according to specifications

For detailed workflow information, see the agents repository.
